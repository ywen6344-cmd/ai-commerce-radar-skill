# Source Map

Use this map for AI, technology, and cross-border commerce research. Favor official sources and original documents.

## AI Models And Developer Ecosystem

Core sources:

- OpenAI API Changelog: https://platform.openai.com/docs/changelog
- OpenAI News: https://openai.com/news/
- Anthropic API Release Notes: https://docs.anthropic.com/en/release-notes/api
- Google AI Developers Blog: https://developers.googleblog.com/en/search/?technology_categories=AI
- Google for Developers Blog: https://developers.googleblog.com/
- Microsoft Azure AI Blog: https://azure.microsoft.com/en-us/blog/topics/ai-machine-learning/
- AWS Machine Learning Blog: https://aws.amazon.com/blogs/machine-learning/
- NVIDIA Technical Blog: https://developer.nvidia.com/blog/

High-value signals:

- Model cost, speed, context, tool use, computer use, web use, multimodal, batch, cache, or fine-tuning changes
- Agent runtimes, MCP/UCP support, browser automation, sandbox execution, and long-running workflow infrastructure
- Official SDKs, API deprecations, rate limits, pricing, usage APIs, and enterprise controls
- Open-source releases in LLM infra, RAG, agent frameworks, browser automation, commerce automation, and catalog/search tooling

## Market, Category, And Competitive Signals

Use these mostly as B/C or supporting signals unless backed by first-party data:

- Amazon Best Sellers, Movers & Shakers, New Releases
- TikTok Shop trending products, affiliate leaderboards, live commerce activity
- Google Trends
- Meta Ad Library
- Similarweb, Semrush, Ahrefs, App Store, Chrome Web Store, Shopify App Store
- Reddit, seller forums, Facebook Groups, Discord communities, creator posts
- Job postings for marketplace manager, AI commerce operator, catalog/feed specialist, retail media, and seller ops

High-value signals:

- Repeated seller pain in the same workflow
- Sudden category growth or repeated ad creative patterns
- New tools getting reviews, integrations, or visible paid adoption
- Hiring clusters around AI commerce, feed, catalog, ads, marketplace ops, or compliance

## Company, Filing, And Capital Signals

Core sources:

- Investor relations pages for Amazon, Shopify, Meta, Google, Microsoft, NVIDIA, Adobe, Salesforce, PayPal, Criteo, BigCommerce
- SEC filings and earnings call transcripts
- Official product launch pages, developer conferences, and regulatory filings

High-value signals:

- Repeated mentions of merchant productivity, AI shopping, retail media, agentic commerce, seller tools, checkout, catalog, or ads automation
- Acquisitions or partnerships in commerce media, AI search, catalog, fulfillment, payments, compliance, or customer support
